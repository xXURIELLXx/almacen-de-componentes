# Prompt para analisis del repositorio por IA

Usa este prompt cuando otra IA deba continuar el inventario.

Analiza el repositorio almacen-de-componentes como una base tecnica de materiales para robotica, sistemas embebidos, IoT y automatizacion.

Prioriza:

1. Seguridad electrica y compatibilidad de voltajes.
2. Validacion de datos antes de energizar componentes.
3. Separacion entre datos confirmados, referencias de PDF y datos pendientes.
4. Proyectos utiles con el material disponible.
5. Recomendaciones de prueba inicial paso a paso.

No asumas que un modulo generico coincide exactamente con una ficha tecnica oficial. Cuando falte un dato, marcame como pendiente y propone una prueba segura para obtenerlo.

Para servos, considera desde el inicio limites mecanicos, inversion de direccion, rampas de movimiento y pruebas sin carga.

Para baterias LiPo, verifica polaridad, voltaje real, estado fisico y cargador compatible antes de recomendar uso.

Para placas recuperadas de drones, no propongas energizar sin antes documentar fotos, chips, conectores, continuidad y consumo limitado.
