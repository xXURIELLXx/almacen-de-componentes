# Imagenes

Carpeta reservada para fotos propias, pinouts verificados, capturas de placas y diagramas de conexion.

## Estado

- Imagenes actuales: ninguna cargada.
- Fotos de componentes reales: pendiente.
- Pinouts verificados por medicion: pendiente.

## Reglas

1. No usar imagenes como prueba definitiva sin validar el componente fisico.
2. Nombrar archivos con minusculas, guiones bajos y componente asociado.
3. Cuando una imagen confirme un pinout, registrar tambien la evidencia en la ficha del componente.
4. Separar imagenes de referencia comercial de fotos propias.
