# Metodologia del repositorio

Trabajo el repositorio como una base tecnica incremental. Cada dato se clasifica por nivel de certeza.

## Niveles de dato

- Confirmado por usuario: dato observado o declarado directamente.
- Referencia de PDF: dato tomado de manual, publicacion o ficha de compra.
- Pendiente de validacion: dato que debe medirse o confirmarse fisicamente.

## Metodo de trabajo

1. Observo el componente y registro nombre, cantidad, modelo y estado.
2. Formulo la hipotesis de funcionamiento: alimentacion, senal y uso probable.
3. Verifico datos con PDF o manual cuando exista.
4. Defino riesgos antes de energizar.
5. Propongo una prueba inicial de baja complejidad.
6. Registro resultado y actualizo el inventario.

## Criterio para IA

La IA debe priorizar seguridad electrica, compatibilidad de voltajes y validacion fisica antes de proponer integraciones complejas.
