# TP4056 / modulo de carga Li-ion LiPo 1S

## Identificacion

- Componente: modulo de carga USB-C / Micro USB con TP4056 o 4056.
- ID relacionado: `PWR-002`.
- Fuente: `PDF-005`, referencia inicial de publicacion de venta.
- Ficha procesada previa: `documentos/procesados/fichas_componentes/PWR-002_TP4056.md`.
- Estado de validacion: pendiente de prueba fisica por unidad.

## Alimentacion

| Campo | Valor | Estado |
|---|---|---|
| Entrada | 5 V por USB-C o Micro USB | referencia inicial |
| Bateria compatible | una celda Li-ion/LiPo 1S, 3.7 V nominal | referencia inicial |
| Corte de carga | 4.2 V +/-1% | referencia inicial |
| Corriente de carga | 1000 mA max | referencia inicial |
| Proteccion de descarga | 2.5 V | referencia inicial |
| Sobrecorriente | 3 A | referencia inicial |

## Pines

| Pin | Funcion | Nota |
|---|---|---|
| `B+` | positivo de bateria | validar polaridad antes de soldar |
| `B-` | negativo de bateria | validar polaridad antes de soldar |
| `OUT+` | salida positiva protegida | usar solo si la placa incluye proteccion real |
| `OUT-` | salida negativa protegida | comun de salida |
| USB-C / Micro USB | entrada 5 V | usar fuente USB estable |

## Uso inicial

1. Inspeccionar serigrafia de cada placa.
2. Medir continuidad para descartar corto entre positivo y negativo.
3. Conectar una sola celda Li-ion/LiPo 1S.
4. Cargar bajo supervision en superficie no inflamable.
5. Vigilar temperatura, polaridad y voltaje de corte.

## Riesgos

- No usar con bateria sellada de 12 V.
- No usar con celdas en serie.
- No invertir polaridad de bateria.
- La corriente de 1 A puede ser excesiva para celdas pequenas.
- No asumir que todas las placas tienen proteccion si no se valida visualmente.

## Prueba recomendada

- Iniciar con una celda 1S en buen estado y multimetro conectado.
- Confirmar voltaje de celda antes, durante y despues de la carga.
- Registrar temperatura aproximada y comportamiento de LEDs de estado.

## Relacion con proyectos

- Alimentacion portatil con LiPo 1S.
- Nodo IoT portable.
- Pruebas con baterias recuperadas solo despues de validar estado.

## Pendiente de validar

- Variante exacta de cada placa.
- Corriente real de carga.
- Presencia real del circuito de proteccion.
- Capacidad minima recomendada de bateria para carga a 1 A.
