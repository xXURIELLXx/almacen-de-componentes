# Ojos LED flexibles para cosplay

## Identificacion

- Componente: ojos LED flexibles para mascara/casco.
- ID relacionado: `LED-002`.
- Fuentes: `PDF-008` y `PDF-009`, referencia inicial de publicacion/manual.
- Estado de validacion: pendiente de prueba fisica antes de cortar.

## Alimentacion

| Campo | Valor | Estado |
|---|---|---|
| Modelo indicado | AAA-0221-07 | referencia inicial |
| Version principal | 2 baterias AAA | referencia inicial |
| Versiones manual | CR2032, 2xAAA, CR2025 o USB 5 V 1 A segun variante | referencia inicial |
| Tamano lente | 27.5 x 76.5 mm | referencia inicial |
| Area efectiva | 27.5 x 69.5 mm | referencia inicial |
| Material | PVC flexible recortable | referencia inicial |

## Conexiones

| Elemento | Funcion | Nota |
|---|---|---|
| Portabaterias | alimentacion segun variante | confirmar tipo real antes de usar |
| USB 5 V | alimentacion en variante USB | solo si la version recibida lo incluye |
| Panel flexible | iluminacion de ojos | no cortar zona LED ni pistas criticas |

## Uso inicial

1. Probar con baterias correctas antes de cortar o pegar.
2. Medir los huecos del casco o mascara.
3. Marcar area de corte sin tocar la zona LED.
4. Fijar con silicon caliente si coincide con la version del manual.
5. Validar visibilidad antes de usar el casco.

## Riesgos

- Reduce vision.
- No mirar luz intensa por tiempo prolongado.
- No usar de noche si afecta visibilidad.
- No retirar pelicula reflectiva sin criterio.
- No usar 502, pegamento instantaneo o pegamento liquido segun manual.
- No sumergir ni exponer a calor/fuego.
- Retirar baterias durante almacenamiento largo.

## Prueba recomendada

- Probar brillo y autonomia antes de instalar.
- Revisar si el calor del adhesivo afecta el panel.
- Confirmar que el usuario pueda ver correctamente con el casco puesto.

## Relacion con proyectos

- Casco Iron Man.
- Cosplay electronico con control tactil.
- Integracion futura con alimentacion y audio, manteniendo circuitos separados.

## Pendiente de validar

- Variante exacta recibida.
- Tipo de bateria real.
- Si el panel puede alimentarse desde otro sistema sin danarlo.
- Area segura de corte en la unidad fisica.
