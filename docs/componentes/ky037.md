# KY-037 sensor de sonido

## Identificacion

- Componente: KY-037 detector de sonido.
- ID relacionado: `SEN-002`.
- Fuente: `PDF-007`, referencia inicial de publicacion de venta.
- Estado de validacion: pendiente de prueba fisica.

## Alimentacion

| Campo | Valor | Estado |
|---|---|---|
| Chip indicado | LM393 | referencia inicial |
| Microfono | electret | referencia inicial |
| Voltaje | 3.3-5 V o 4-6 V segun seccion | referencia inicial con contradiccion |
| Salida | digital por umbral, efectiva en bajo segun PDF | referencia inicial |
| Ajuste | potenciometro | referencia inicial |

## Pines

| Pin | Funcion | Nota |
|---|---|---|
| `VCC` | alimentacion | iniciar con 5 V en Arduino para primera prueba |
| `GND` | tierra | tierra comun |
| `OUT` / `DO` | salida digital | confirmar si es activa en bajo |
| `AO` | salida analogica | solo si la variante la incluye |

## Uso inicial

1. Probar primero con Arduino a 5 V.
2. Leer `OUT` como entrada digital.
3. Ajustar el potenciometro hasta detectar palmadas o ruido cercano.
4. Confirmar si la salida cambia a bajo o alto al detectar sonido.

## Riesgos

- No mide decibeles reales.
- No reconoce palabras ni frecuencia.
- Para ESP32, validar nivel logico antes de conectar.
- Puede activarse por ruido ambiental o vibracion.

## Prueba recomendada

- Usar monitor serial para registrar cambios de `OUT`.
- Probar con diferentes sensibilidades.
- Registrar si el modulo incluye salida analogica real.

## Relacion con proyectos

- Entrada por ruido para demostraciones.
- Activacion simple por palmada.
- Pruebas de sensores digitales con Arduino.

## Pendiente de validar

- Rango real de alimentacion de la placa recibida.
- Polaridad de salida.
- Presencia de `AO` en la variante fisica.
