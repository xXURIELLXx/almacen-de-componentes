# Prioridades de proyectos

## Prioridad 1: alimentacion segura

Separar lineas de 3.3 V, 5 V, 12 V y baterias LiPo 1S. Esta base evita danar modulos durante pruebas.

## Prioridad 2: calibrador de servos

Crear un banco para probar SG90 con limites minimo, maximo, centro e inversion de direccion. Este proyecto atiende el antecedente de servos quemados por recorrido invertido o sobreesfuerzo.

## Prioridad 3: nodo ambiental IoT

Usar ESP32 con sensores AHT10/DHT, PIR y pantalla TFT. Sirve como base para terrario, cuarto seco de filamento o agente fisico.

## Prioridad 4: comunicacion NRF24L01

Crear enlace simple entre dos nodos: transmisor con boton y receptor con salida visible. Agregar capacitor cerca del modulo RF.

## Prioridad 5: banco de motores DC

Probar motores de 5 V con driver. Registrar corriente sin carga, sentido de giro y respuesta PWM.

## Prioridad 6: recuperacion de drones

Documentar placas YD-W6833-v.1c y HY-2016R a con fotos, chips, continuidad y consumo antes de energizar.
